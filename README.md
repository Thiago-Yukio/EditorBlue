# EditorBlue

O **EditorBlue** é uma aplicação web desenvolvida com **Streamlit** que permite editar e manipular textos de forma simples e intuitiva diretamente pelo navegador.

---

## Tecnologias Utilizadas

- Python
- Streamlit
- pypdf
  



## Sobre o Projeto

O EditorBlue foi criado com o objetivo de oferecer uma ferramenta prática para edição de textos, utilizando a simplicidade e a rapidez de desenvolvimento proporcionadas pela biblioteca Streamlit.

Este projeto representa uma das primeiras experiências com a criação e publicação de aplicações web em Python, demonstrando como é possível transformar scripts em aplicações acessíveis pela internet de forma rápida e eficiente.
